4. Issues / Risks Found and Fixes

During development, I identified some limitations in the AI-assisted code:

The agent uses keyword matching, so it may classify a question incorrectly if none of the expected keywords are present.
A question containing a keyword from one category may be classified into that category even when the user's actual intention is different.
The agent does not understand the meaning of a question like a full AI chatbot; it only follows predefined rules.

I tested the program with different inputs and checked the output. The final code was kept simple so that the working of the rule-based agent could be clearly understood.
